1. Brity 과제 실행 챗봇
개발기간: 2024.08 ~ 2024.11
· 개요: Brity Assistant 기반으로, 현업 사용자가 대화형으로 RPA 과제를 직접 실행할 수 있는 챗봇 개발.
· 수행 역할: 챗봇 시나리오 설계 및 RPA 과제 호출 로직 구현. 사용자 요청을 파싱하여 해당 Brity 봇을 트리거하는 인터페이스 개발 담당.
2. 비가동 봇 탐지 및 자동 재실행
개발기간: 2025.01 ~ 2025.03
· 개요: n8n과 RPA를 연동하여 Brity 봇의 비가동 상태를 주기적으로 모니터링하고, 일정 시간 이상 비가동 시 자동으로 재부팅하는 체계 구축.
· 수행 역할: n8n 워크플로우 설계 및 개발, 봇 상태 점검 로직과 재부팅 트리거 조건(임계 시간) 정의. 무인 운영 환경에서의 장애 대응 시간을 단축하여 운영 안정성 개선에 기여.
3. Brity 혁신과제 개발 (2건)
