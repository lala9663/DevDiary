# 📡 File Classification Agent — HTTP API 스펙

> 목적: Flowise Agent를 외부(n8n, 기타 서비스)에서 HTTP로 호출해  
> 파일 메타데이터/분류 정보를 JSON으로 받기 위한 API 스펙 정의.

---

## 1. 개요

이 API는 **파일 분류 전용 Flowise Agent**를 호출하기 위한 엔드포인트이다.

- 입력: 파일명, 확장자, 파일 내용(텍스트)
- 출력: 프로젝트명, 연/월, 문서 유형, 폴더 경로, 추천 파일명, 태그, 보안 정책

이 API는 나중에:

- n8n (Gmail Trigger / Drive Trigger)
- 별도 백엔드 서비스
- CLI 스크립트

등에서 공통으로 사용할 수 있는 **표준 인터페이스**가 된다.

---

## 2. Endpoint 개념

> 실제 URL은 Flowise 환경에 따라 다름.  
> 아래는 형태 예시이며, `<FLOW_ID>` 및 Base URL은 환경에 맞게 교체 필요.

```http
POST https://YOUR-FLOWISE-URL/api/agent/<FLOW_ID>
Content-Type: application/json
Authorization: Bearer YOUR_API_KEY (선택)
```

- **Method**: `POST`
- **Auth**: 필요 시 API Key / JWT 등 (Flowise 설정에 따름)
- **Body**: JSON (아래 Request 형식 참고)

---

## 3. Request 형식

### 📥 Request JSON

```json
{
  "fileName": "프로젝트A_회의록_2025-09-14_v2.docx",
  "fileExtension": "docx",
  "fileContent": "2025년 9월 14일 프로젝트A 개발팀 회의록입니다. 참석자: ..."
}
```

### 필드 설명

- `fileName` (`string`)  
  - 실제 파일명 (확장자 포함/미포함 중 하나로 정책 통일)
- `fileExtension` (`string`)  
  - `docx`, `pdf`, `xls`, `pptx` 등 확장자
- `fileContent` (`string`)  
  - 파일에서 추출한 텍스트 내용  
  - 전문 또는 요약 (정책에 따라 결정)

> 나중에 n8n에서:
> - Gmail 첨부파일 내용 추출 → `fileContent`
> - 파일명, 확장자 → `fileName`, `fileExtension`
> 로 매핑해서 이 JSON을 구성하면 된다.

---

## 4. Response 형식

### 📤 Response JSON

```json
{
  "projectName": "프로젝트A",
  "year": "2025",
  "month": "09",
  "docType": "회의록",
  "finalFolderPath": "/프로젝트A/2025/09/회의록",
  "newFileName": "프로젝트A_회의록_2025-09-14_v2.docx",
  "tags": ["프로젝트A", "회의록"],
  "storageType": "public"
}
```

### 필드 설명

- `projectName` (`string`)  
  - 프로젝트명 또는 업무명 (예: `"프로젝트A"`, `"Apollo"`)
- `year` (`string`)  
  - 연도 (예: `"2025"`, 없으면 `""`)
- `month` (`string`)  
  - 월 (예: `"09"`, 없으면 `""`)
- `docType` (`string`)  
  - 문서 유형  
  - `"회의록" | "계약서" | "견적서" | "인보이스" | "보고서" | "매뉴얼" | "기타"`
- `finalFolderPath` (`string`)  
  - 추천 폴더 경로  
  - 기본: `"/{projectName}/{year}/{month}/{docType}"`  
  - 연/월 없으면: `"/{projectName}/{docType}"`
- `newFileName` (`string`)  
  - 추천 파일명 (예: `"프로젝트A_회의록_2025-09-14_v2.docx"`)
- `tags` (`string[]`)  
  - 태그 리스트 (예: `["프로젝트A","회의록"]`)
- `storageType` (`string`)  
  - 보안 정책  
  - `"public" | "private" | "confidential"`

## 6. n8n 연동 시나리오 (요약)

> 자세한 n8n Flow는 별도 문서에서 설계.  
> 여기서는 상호작용 개념만 기록.

1. **Gmail Trigger (n8n)**
   - 새 메일 도착 시 이벤트 발생
   - 첨부파일 메타데이터 및 내용 추출

2. **HTTP Request → Flowise Agent**
   - 위 Request JSON 형식으로 POST
   - Response로 분류 결과 JSON 수신

3. **Google Drive 노드**
   - `finalFolderPath` 기준으로 폴더 생성/이동
   - `newFileName`으로 파일명 변경
   - `tags`, `storageType` 기반으로 메타데이터/권한 처리

## 7. 버전 관리 메모

- v1.0
  - 최초 정의: fileName, fileExtension, fileContent → Agent JSON 분류 결과 반환
  - Folder path 빈 연/월 케이스 처리:
    - year & month 없을 경우 → `"/{projectName}/{docType}"`

- 향후 개선 예정:
  - `language`, `source` 필드 추가 가능성 (예: `"email"`, `"drive"`)
  - batch 처리 (여러 파일 동시에 분류)
  - 결과 로그 저장용 API 추가
